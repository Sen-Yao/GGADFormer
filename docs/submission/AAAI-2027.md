## 摘要截止前必须完成

摘要注册不是占位。AAAI 明确要求完整标题和完整摘要；`test`、`xyz` 等占位内容会被删除，作者随后不能补交全文。摘要到全文之间发生实质性改写也可能被无审稿拒绝。

## 最短操作流程

1. 用最终作者各自的 OpenReview profile 注册 AAAI-27 submission site。
2. 在摘要截止前创建 `AAAI 2027 Conference Submission`，填完标题、作者、TLDR、摘要、topics、单位国家、互惠审稿人确认和三项政策声明。
3. 保存后打开 paper forum，检查作者列表、字段值和 deadline 状态；OpenReview 不会自动发送收件确认，可用页面右上角的 `Email` 按钮发给自己或全体作者。
4. 在全文截止前上传匿名主 PDF，并完成可修改的标题/作者最终核对。
5. 在补充材料截止前上传需要审稿的 checklist、technical supplement、media 或 code/data archive。

每位作者在 AAAI-27 technical track 的投稿数上限为 10 篇；作者也应加入会议 reviewer pool，符合资格且无正当例外时需要承担轻量评审任务。

### 1. 所有作者的 OpenReview profile

- 所有作者必须在提交前拥有 OpenReview profile。
- 各次投稿和审稿任务必须使用同一个 OpenReview 账户和邮箱。
- profile 应包含完整发表姓名、当前职位、单位邮箱和可用的 DBLP URL。
- 如果 DBLP 是消歧页且无法填写，应使用 AAAI 提供的 DBLP Disambiguation Declaration Form。
- 提交后不能新增作者；标题和作者修改只允许到全文截止前。

当前工作区没有可靠的完整作者名单与单位信息，因此这些字段必须由投稿团队核对，不能从匿名 PDF 或旧 metadata 自动填充。

### 2. 论文表面字段

| OpenReview 字段 | 要求 | VecGAD 建议 |
|---|---|---|
| `Title` | 必填，1-250 字符 | 使用下文建议标题，不用占位标题 |
| `Authors` | 由 author profiles 生成 | 加入全部且仅加入最终作者 |
| `TL;DR` | 必填，最多 250 字符 | 使用一句机制和任务边界明确的陈述 |
| `Abstract` | 必填，最多 5000 字符，支持 Markdown/TeX | 提交接近最终版的完整摘要 |
| `Primary Topic` | 必填，203 个枚举项中选 1 个 | `DMKM: Anomaly Detection & Pattern Mining` |
| `Secondary Topics` | 可选，最多 5 个 | 建议只选 3 个，见下文 |
| `Country of Institutions` | 必填，多选 | 选择每位作者当前单位所在地，不是国籍 |

AAAI 2027 没有自由文本 `Keywords` 字段。Topics 的主要作用是匹配 reviewer，选得过宽可能引入并不理解论文主线的 reviewer。

### 3. Topics 推荐

Primary topic：

> `DMKM: Anomaly Detection & Pattern Mining`

理由：当前论文的主要贡献对象是 graph anomaly detection；最需要 anomaly detection reviewer 判断任务设定、baseline 和指标。

Secondary topics：

1. `ML: Graph-based Machine Learning`
2. `ML: Semi-Supervised & Active Learning`
3. `ML: Deep Generative Models & Autoencoders`

不建议为了覆盖旧 Keywords 而凑满五项。只有当 AAAI 版本提供了正式的规模/效率实验并把可扩展性提升为中心贡献时，再增加 `ML: Scalability of ML Systems`。`Transformer` 和 `Hard Negative Generation` 没有一一对应的 AAAI topic。

如果 AAAI 版本把主要贡献改写为可迁移的通用 Graph ML 表征方法，而 GAD 只作为应用验证，则可把 primary 改为 `ML: Graph-based Machine Learning`，并将 anomaly topic 放到 secondary；两者不能同时作为 primary。当前代码和 KDD 题目仍更支持前面的 DMKM primary 建议。

### 4. 互惠审稿人提名

这是最容易漏掉的时限：**提名在 2026-07-21 AoE 后不能修改**。

- 如作者中存在合格人选，应提名一名作者。
- 人选不能是 AAAI 2027 的 SPC、AC 或 Organizer。
- 人选需在 AAAI 相关的同行评审 archival venue 中满足至少 2 篇一作论文，或至少 5 篇合著论文；workshop 不计。
- 被提名人同意担任 PC Member，若分配任务需完成最多 6 篇评审。
- 有合格作者却不提名，或被提名人不履行评审，投稿可能 desk reject。

表单的 nominee profile 字段技术上是 optional，但确认项必填，只能二选一：

1. 已提名合格作者；
2. 声明没有任何作者符合资格，并理解错误声明可能导致 desk rejection。

如果候选人的 OpenReview profile 因 DBLP 消歧页无法记录链接，可另填 `Reciprocal Reviewer DBLP URL`。具体候选人属于作者团队决策，本工作区不能代填。

### 5. 政策确认

必须勾选三项：

1. 所有作者的 OpenReview profiles 完整且最新；
2. 该稿或实质相似稿件没有同时在其他 archival venue 审稿；
3. 任一作者的相关同期投稿已在匿名稿中以 `under review` 形式引用。

KDD 2026 已拒稿本身不构成 simultaneous submission。确认时仍需检查当前是否存在新的期刊或会议在审版本。AAAI 允许 arXiv 等 preprint 和 non-archival workshop，但不允许同时投 archival conference/journal。

### 6. 可选字段

- `Self-Declared Conflict of Interest`：只添加真实、可解释的冲突 profile。
- `PDF`：在摘要阶段 schema 中 optional；全文截止时必须上传。
- `Reproducibility Checklist`：schema 暂标 optional，但官方 Submission Instructions 明确要求全文提交时单独上传，正式政策优先。
- `Technical Supplement`、`Media Supplement`、`Code and Data Supplement`：摘要阶段不需要。

系统会自动设置 venue、venue id 和 `CC BY 4.0` license，不需要手工选择。

## VecGAD 文案复用评估

### 标题

KDD 标题形式上可直接提交，但不建议原样复用。推荐：

> **VecGAD: Vectorized Reconstruction Discrepancy for Label-Efficient Graph Anomaly Detection**

相较 KDD 标题，该版本：

- 把方法名放入标题，便于建立论文与代码的对应关系；
- 用 `Reconstruction Discrepancy` 明确向量来源，而不是较泛的 `Discrepancy`；
- 保留任务和 label-efficient 设定；
- 没有引入超出当前证据的 SOTA 或 scalability claim。

### TLDR

KDD TLDR 尚未从 OpenReview 取回，不应假定它与当前主线一致。AAAI 候选版本：

> VecGAD projects vectorized reconstruction discrepancies into embedding space to generate shell-constrained hard negatives for graph anomaly detection with scarce labeled normal nodes.

该句少于 250 字符，包含输入信号、核心动作、生成对象和监督边界。

### 摘要

KDD 摘要可通过 AAAI 字段长度校验，但不建议直接粘贴。主要问题：

- `precisely captures how each node deviates from normality` 把设计动机写成了已证明的精确语义；
- `significantly outperforms state-of-the-art methods` 没有在摘要中绑定 dataset、split、seeds 或统一后的结果；
- 没有清楚呈现离线图传播与 mini-batch Transformer 的可扩展路径；
- 当前仓库不同文档的部分结果数字尚未统一，不能据此写定量 claim；
- AAAI 不允许摘要截止后实质性改写，因此注册时就应使用接近最终主线的版本。

可用于摘要注册的保守草稿如下，最终版必须在实验表和 KDD review 整改完成后再冻结：

> Graph anomaly detection often operates with only a small set of labeled normal nodes, making it difficult to learn a reliable decision boundary for diverse and previously unseen anomalies. We present VecGAD, a Transformer-based autoencoder for label-efficient graph anomaly detection. VecGAD decouples graph propagation from mini-batch representation learning and retains reconstruction error as a vectorized directional signal rather than reducing it to a scalar score. It projects this discrepancy into the embedding space to generate pseudo-anomalies and constrains them to a hyperspherical shell, producing challenging negatives without using anomaly labels. A lightweight classifier then learns to distinguish labeled normal nodes from the generated negatives. Experiments on seven real-world graphs under multiple label-scarce settings evaluate detection quality, robustness to label scarcity, and the contributions of discrepancy direction and shell constraints.

### KDD Keywords 到 AAAI Topics 的映射

| KDD Keyword | AAAI 处理 |
|---|---|
| Graph Anomaly Detection | Primary: `DMKM: Anomaly Detection & Pattern Mining` |
| Semi-supervised Learning | Secondary: `ML: Semi-Supervised & Active Learning` |
| Label Scarcity | 不单独选择；由 semi-supervised topic 和摘要表达 |
| Transformer | 不单独选择；放在标题/摘要/方法中 |
| Hard Negative Generation | Secondary 可由 `ML: Deep Generative Models & Autoencoders` 覆盖 |

## 全文与补充材料

- Main paper：AAAI 双栏、US Letter、double blind。
- 最多 7 页正文；第 8-9 页只能放 references。
- acknowledgements 必须删除；ethics statement 若需要，计入 7 页正文。
- 主 PDF 最大 10 MB。
- Reproducibility Checklist 单独 PDF，最大 5 MB，全文提交时必交。
- Technical Supplement：可选 PDF，最大 10 MB；正文必须自洽，reviewer 无义务阅读。
- Media Supplement：可选 ZIP，最大 50 MB。
- Code and Data Supplement：可选 ZIP，最大 50 MB。
- 禁止在稿件或补充材料中链接外部代码/数据仓库，包括 AnonymousGitHub；需把供审稿的代码和数据直接放入 Code and Data Supplement。

## 评审流程

Main Track 采用两阶段评审：

1. Phase 1：至少两份人类评审，并附一份不参与正式决策的 AI-generated review；
2. 未在 Phase 1 被拒的论文进入 Phase 2，获得额外人类评审；
3. 只有 Phase 2 论文进入 author feedback；
4. SPC 综合 reviews、author response 和讨论给出建议，最终决定仍由人类作出。

## 仍需作者团队确认

- 最终作者顺序、OpenReview profiles 和各单位国家；
- 互惠审稿人 nominee 及资格；
- KDD TLDR、reviews、author response 和 decision comment；
- AAAI 最终标题是否采用带 `VecGAD:` 的版本；
- 统一后的实验 protocol、表格数字和可在摘要中声明的结果强度。
